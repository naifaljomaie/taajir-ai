# 🚀 Wasf AI | وصف AI
أداة ذكاء اصطناعي مخصصة للتجار وأصحاب المتاجر الإلكترونية لتوليد وصف تسويقي وإعلانات جذابة للمنتجات باللغة العربية واللهجات المحلية.

---

### 🌟 ميزات الأداة:
* **وصف منتجات بيّاع:** صياغة نصوص تسويقية موجهة بالكامل للجمهور العربي والخليجي.
* **منشورات جاهزة:** توليد محتوى جاهز للنشر على تليجرام، واتساب، وتيك توك بضغطة زر.
* **هاشتاقات نشطة:** اقتراح أفضل الهاشتاقات المناسبة لكل منتج لزيادة الوصول.

---

### 🛠️ التقنيات المستخدمة:
* **الواجهة الأمامية:** HTML5, CSS3, JavaScript
* **الذكاء الاصطناعي:** Gemini AI / OpenAI API
* **الاستضافة:** Vercel
